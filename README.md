# Fanzy Projects

Una aplicación de escritorio para organizar y llevar el control de tus proyectos de cómic.

![Alternative text](/2026-09-21_13-45.png "Screenshot")

## Qué hace

Fanzy Projects te ayuda a gestionar todo el proceso creativo de un cómic en un solo lugar:

- **Páginas**: estructura tu proyecto en páginas y muévete por ellas con facilidad.
- **Tareas por página**: define las etapas de cada página (boceto, tinta, color, texto…) y márcalas como completadas cuando las termines.
- **Seguimiento de horas**: registra las horas dedicadas a cada tarea y consulta el total invertido en tu proyecto.
- **Progreso visual**: la interfaz muestra de un vistazo qué está terminado y qué queda por hacer.
- **Proyectos independientes**: crea, cierra, importa y exporta tus proyectos en cualquier momento.

Funciona en las tres plataformas principales: **Linux**, **macOS** y **Windows**.

## Instalación

Elige tu sistema operativo y descarga el archivo correspondiente de la página de *Releases*.

### Linux

Tienes dos opciones:

- **Paquete `.deb`** (recomendado para Debian, Ubuntu y derivadas):
  ```bash
  sudo apt install ./fanzyprojects_*.deb
  ```
  Lanza la aplicación desde el menú de tu escritorio o escribiendo `fanzyprojects` en la terminal.

- **AppImage**: no requiere instalación. Dale permisos de ejecución y ábrelo:
  ```bash
  chmod +x FanzyProjects-*.AppImage
  ./FanzyProjects-*.AppImage
  ```

### macOS

1. Descarga el archivo `FanzyProjects-*-macos.dmg`.
2. Ábrelo y arrastra **Fanzy Projects** a la carpeta **Aplicaciones**.
3. La primera vez puede ser necesario hacer clic con el botón derecho sobre la aplicación y elegir *Abrir*.

### Windows

1. Descarga el instalador `FanzyProjects-*-windows-installer.exe`.
2. Ejecútalo y sigue los pasos del asistente.
3. La aplicación quedará disponible en el menú de inicio y en el escritorio.

## Desinstalación

- **Linux (.deb)**: `sudo apt remove fanzyprojects`
- **macOS**: arrastra la aplicación a la papelera.
- **Windows**: usa *Agregar o quitar programas* del panel de control.
